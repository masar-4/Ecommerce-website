
# 📦 DeckedOut E-Commerce Website

Modern full-stack e-commerce application with user features, cart system, and product browsing.

## 🚀 Tech Stack

* **Frontend:** React + Vite, Axios, React Router
* **Styling:** Tailwind / Bootstrap
* **Backend:** Node.js, Express.js
* **Database:** MongoDB 
* **Dashboard:** React + Axios

---

# 🛠️ Project Features

### 👤 Customer Features


* Browse products
* Product details page
* Add to cart
* Checkout flow


### 🛡️ Admin Features

* Product Management (CRUD)
* Category Management
* Dashboard analytics

# ▶️ How to Run the Project

## 1️⃣ Frontend (Customer Website)

```
cd frontend
npm install
npm install( react-vite / react-router-dom / bootstrab / fontawsome / tailwind axios)
npm run dev
```

Open: **[http://localhost:5173](http://localhost:5173)**

## 2️⃣ Backend (API Server)

```
cd backend
npm install
npm install (cors)
npm start
```

Runs on: **[http://localhost:4000](http://localhost:4000)**

## 3️⃣ Admin Dashboard

```
cd dashboard
npm install
npm run dev
```

Open: **[http://localhost:5174](http://localhost:5174)**

# 🔌 API Endpoints


## Products

| Method | Endpoint            | Description      |
| ------ | ------------------- | ---------------- |
| GET    | `/api/products`     | Get all products |
| GET    | `/api/products/:id` | Get product      |
| POST   | `/api/products`     | Add product      |
| PATCH  | `/api/products/:id` | Update product   |
| DELETE | `/api/products/:id` | Delete product   |

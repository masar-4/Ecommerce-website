# DeckedOut – Full-Stack E-Commerce Application

# A modern e-commerce platform built with a React + Vite frontend and Node.js + Express backend, featuring a product catalog, cart system, checkout flow, and API integration.

# 🚀 Features
# Frontend

🏠 Fully responsive modern UI

🧥 Product categories (Denim, Tees, Men, Women…)

🛒 Shopping cart (Context API + localStorage)

🔍 Search products

💳 Checkout with shipping value

🧩 Reusable components

🌗 Overlay & Navbars

⚡ Built using Vite for faster development
